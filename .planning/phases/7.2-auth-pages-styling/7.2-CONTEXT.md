# Phase 7.2: Auth Pages (Login + Signup) - Context

**Gathered:** 2025-06-25
**Status:** Ready for planning

<domain>
## Phase Boundary

Convert Login and Signup pages from plain CSS (session-background, session-form, auth-buttons) to shadcn components with Tailwind styling. Each page gets a modern split layout with a static illustration side and a form side. This is purely a UI conversion — authentication logic stays as-is (Redux thunks, error handling).
</domain>

<decisions>
## Implementation Decisions

### Form Layout
- **D-01:** Split layout — left side has a static illustration/decorative visual, right side has the form card
- **D-02:** Illustration side shows a static SVG or decorative element related to home/building design (not feature list or branding)
- **D-03:** Background uses gradient (`bg-gradient-to-b from-background to-muted/30`) similar to HomePage

### Error Handling
- **D-04:** Errors displayed as an Alert banner at the top of the form (not inline field errors). Single banner for all error types (server, validation).
- **D-05:** Use shadcn `<Alert variant="destructive">` for error display
- **D-06:** Error text is clear and user-friendly (not raw API messages)

### Extra Fields
- **D-07:** Password visibility toggle (eye icon) — use a Button with eye/eye-off icon inside InputGroup
- **D-08:** No "Forgot Password" link for now
- **D-09:** No "Remember Me" checkbox
- **D-10:** Signup form has: Email, Password, Confirm Password fields only
- **D-11:** Use shadcn `<Input>` with `<Label>` for all form fields

### Mobile / Responsive
- **D-12:** On mobile: form takes full screen, illustration side is hidden
- **D-13:** On desktop: split layout with illustration on left, form on right
- **D-14:** Form card has max-width constraint (~400px)

### Component Choices
- **D-15:** Form wrapper: shadcn `<Card>` with `<CardHeader>`/`<CardContent>`
- **D-16:** Input fields: shadcn `<Input>` with `<Label>`
- **D-17:** Submit button: shadcn `<Button variant="default" className="w-full">`
- **D-18:** Password toggle: eye icon inside Input via `InputGroup` + `InputGroupAddon`

### the agent's Discretion
- Exact illustration/SVG choice for the split layout side
- Color scheme details (within shadcn theme constraints)
- Animation/transition details on form submission
- Password visibility toggle implementation details

</decisions>

## Existing Code Insights

### Reusable Assets
- **shadcn components**: Button, Card, Input, Label, Alert — all installed and ready
- **`@/` alias**: Works with Vite — use `@/components/ui/button` style imports
- **`cn()` utility**: Available in `@/lib/utils` for conditional classes

### Established Patterns
- **Page pattern**: `src/pages/HomePage/HomePage.jsx` shows the pattern (shadcn Card with Tailwind classes)
- **Theme**: Uses shadcn dark/light/blueprint themes via CSS variables
- **Routing**: react-router-dom with `useNavigate`

### Integration Points
- Auth forms dispatch Redux thunks (`thunkLogin`, `thunkSignup`) from `src/redux/session.js`
- Error handling returns `{ success, detail }` objects from thunks
- Successful login navigates to `/editor`, signup navigates to `/login`
