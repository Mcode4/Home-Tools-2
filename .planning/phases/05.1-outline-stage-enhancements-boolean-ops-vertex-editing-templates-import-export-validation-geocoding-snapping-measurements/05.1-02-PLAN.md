  <action>
Create `frontend/src/functions/outlineExport.js` with three export functions. All functions accept an `outlines` array and optional `options` object.

**`exportGeoJSON(outlines, options)`**: Convert outlines array to GeoJSON FeatureCollection. Each outline becomes a Feature with:
- Geometry: For polygons, use `points` or `pointsGeo` coordinates. For rectangles/circles, compute polygon approximation (8 points for circles). Coordinate format: `[[lng, lat], ...]` (GeoJSON standard).
- Properties: name, type, fill, stroke, strokeWidth, opacity, widthMeters, heightMeters
- If outline has `lat`/`lng` and `widthMeters`/`heightMeters`, compute corner coordinates from center + dimensions
- Return: JSON string of FeatureCollection

**`exportSVG(outlines, options)`**: Generate an SVG string with:
- viewBox calculated from outline bounding box (min/max x,y with 10% padding)
- Each outline rendered as a `<polygon>` or `<rect>` or `<circle>` SVG element
- Use outline's fill, stroke, strokeWidth, opacity attributes
- For polygons: `points` attribute as "x1,y1 x2,y2 ..."
- For rectangles: `<rect x y width height>`
- For circles: `<circle cx cy r>`
- Return: SVG string with proper XML header

**`exportPDF(outlines, options)`**: Generate PDF using jspdf (dynamic import):
- Import `jspdf` dynamically: `const { jsPDF } = await import('jspdf')`
- Create A4 landscape document
- Calculate scale to fit all outlines on page
- Render each outline as filled polygon using `doc.setFillColor()` and `doc.poly()` or `doc.rect()`
- Add title text with property name if provided in options
- Return: PDF blob via `doc.output('blob')`

**`parseGeoJSON(jsonString)`**: Parse a GeoJSON string and convert to outlines array format:
- FeatureCollection → array of outlines
- Each Feature with Polygon geometry → outline with `points` as `[lat, lng]` pairs (reversed from GeoJSON)
- Feature with Point geometry → outline with `lat`, `lng`
- Preserve properties as outline attributes
- Return: outlines array

**`parseDXF(dxfString)`**: Parse DXF string using dxf-parser (dynamic import):
- Import `dxf-parser` dynamically: `const DxfParser = (await import('dxf-parser')).default`
- Parse DXF string, extract POLYLINE and LWPOLYLINE entities
- Convert DXF points (meters) to outline points array
- Skip TEXT, DIMENSION, INSERT entities (focus on polylines only)
- Return: outlines array with points in meters

All functions should handle edge cases: empty arrays, missing coordinates, degenerate polygons. Use try-catch for dynamic imports (dxf-parser and jspdf may not be installed yet — return graceful error messages).
