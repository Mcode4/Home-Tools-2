Create `frontend/src/functions/booleanOps.js` with three boolean operation functions. All functions accept two outline objects and return a new outline object or null on failure.

**`booleanUnion(outlineA, outlineB)`**:
- Convert both outlines to Turf.js GeoJSON Polygon features using their points (screen coords)
- Call `turf.union(turf.featureCollection([polyA, polyB]))`
- Extract resulting coordinates, convert back to outline format with normalized points
- Return new outline: `{ type: "polygon", points: normalizedPoints, fill: outlineA.fill, stroke: outlineA.stroke }`

**`booleanSubtract(outlineA, outlineB)`**:
- Convert both to GeoJSON Polygon features
- Call `turf.difference(polyA, polyB)`
- Handle case where result is null (B doesn't overlap A) — return outlineA unchanged
- Handle case where result is MultiPolygon — take the largest polygon by area
- Return new outline from result

**`booleanIntersect(outlineA, outlineB)`**:
- Convert both to GeoJSON Polygon features
- Call `turf.intersect(turf.featureCollection([polyA, polyB]))`
- Handle null result (no overlap) — return null
- Return new outline from intersection

Helper: `outlineToTurfFeature(outline)` — convert outline to GeoJSON Polygon feature:
- If outline has `points` array (normalized [[x,y], ...]): use screen coords directly as polygon coordinates
- If outline has `lat`, `lng`, `widthMeters`, `heightMeters`: compute 4 corners from center + dimensions
- Return `turf.polygon([coordinates])` where coordinates is `[[[x1,y1],[x2,y2],[x3,y3],[x4,y4],[x1,y1]]]` (closed ring)

Helper: `featureToOutline(feature, sourceOutline)` — convert GeoJSON feature to outline:
- Extract coordinates from feature.geometry.coordinates[0]
- Normalize points to min/max (shift so min x,y is 0,0)
- Preserve fill, stroke, strokeWidth from sourceOutline
- Return outline object

**handleBooleanOp callback**:
```jsx
const handleBooleanOp = useCallback((opType) => {
    if (multiSelectIds.length < 2) return;
    const outlinesA = outlines.filter(o => multiSelectIds.includes(o.id));
    if (outlinesA.length < 2) return;
    let result = outlinesA[0];
    for (let i = 1; i < outlinesA.length; i++) {
        if (opType === "union") result = booleanUnion(result, outlinesA[i]);
        else if (opType === "subtract") result = booleanSubtract(result, outlinesA[i]);
        else if (opType === "intersect") result = booleanIntersect(result, outlinesA[i]);
        if (!result) break;
    }
    if (result) {
        const newId = `shape-${Date.now()}`;
        result.id = newId;
        setOutlines(prev => [...prev.filter(o => !multiSelectIds.includes(o.id)), result]);
        setMultiSelectIds([]);
        setSelectedShapeId(newId);
    }
}, [multiSelectIds, outlines, setOutlines]);
```
