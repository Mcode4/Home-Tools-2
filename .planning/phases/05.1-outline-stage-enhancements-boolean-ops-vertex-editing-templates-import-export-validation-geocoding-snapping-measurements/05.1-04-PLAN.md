Create `frontend/src/functions/outlineValidation.js` with validation and measurement functions.

**`validateOutlines(outlines, options)`**: Main validation entry point. Accepts outlines array and options `{ minArea: 1, checkOverlaps: true }`. Returns `{ isValid, warnings, measurements }`.

Validation checks (each returns warnings array):

1. **Self-intersection check**: For each polygon outline with `points` array:
   - Convert points to Turf.js Polygon feature using `outlineToTurfPolygon(outline)` helper
   - Use `turf.kinks(polygon)` to detect self-intersections
   - If `selfIntersections.length > 0`, add warning: `{ type: "self-intersection", outlineId, message: "Polygon self-intersects at N points", severity: "error" }`

2. **Overlap check** (when `checkOverlaps` is true):
   - For each pair of outlines, convert both to Turf features
   - Use `turf.booleanOverlap(polyA, polyB)` to check edge crossings
   - Use `!turf.booleanDisjoint(polyA, polyB)` to check any overlap
   - If overlap detected: `{ type: "overlap", outlineId: [idA, idB], message: "Outlines A and B overlap", severity: "warning" }`

3. **Min-size check**: For each outline:
   - Compute area using `getOutlineArea(outline)`
   - If area < `minArea` (default 1 sq meter): `{ type: "min-size", outlineId, message: "Outline area (X sq m) below minimum (Y sq m)", severity: "warning" }`

**`getOutlineArea(outline)`**: Compute area in square meters.
- Convert outline to Turf feature
- If outline has `lat`, `lng`, `widthMeters`, `heightMeters`: compute area = widthMeters * heightMeters (for rectangles)
- Otherwise: `turf.area(feature)` returns square meters
- Return number (square meters)

**`getOutlinePerimeter(outline)`**: Compute perimeter in meters.
- Convert outline to Turf feature
- `turf.length(feature, { units: 'meters' })`
- For rectangles without points: 2 * (widthMeters + heightMeters)
- Return number (meters)

**`outlineToTurfPolygon(outline)`**: Internal helper to convert outline to Turf Polygon feature.
- If outline has `points` array: create polygon ring `[[[x,y], ..., [x,y]]]` (close ring by repeating first point)
- If outline has `lat`, `lng`, `widthMeters`, `heightMeters`: compute 4 corners as polygon
- If outline has `sides` (regular polygon): compute vertices from center + radius
- Return `turf.polygon([ring])`

**`metersToUnit(meters, unit)`**: Convert meters to display unit.
- If unit === "imperial": return `{ value: meters * 3.28084, label: "ft" }` for length, `{ value: meters * 3.28084 * 3.28084, label: "sq ft" }` for area
- If unit === "metric" (default): return `{ value: meters, label: "m" }` or `{ value: meters, label: "sq m" }`
- Return `{ value, label }`

**`checkEdgeSnap(outlineA, outlines, threshold)`**: Find nearest edge/vertex of other outlines within threshold pixels.
- For each vertex and edge midpoint of other outlines, compute distance to each vertex of outlineA
- Return `{ snapPoint: {x, y}, targetOutlineId }` if within threshold, else null

**`checkAlignmentGuides(outline, outlines)`**: Check if centers or edges of outline align with any other outline.
- Compute center of outline (centroid)
- For each other outline, compute center
- If centers have same x or y coordinate (within 5px tolerance): return alignment guide `{ type: "center", axis: "x"|"y", value, fromOutlineId, toOutlineId }`
- Also check edge alignment: left/right/top/bottom edges within tolerance
- Return array of alignment guides

Export all functions: `validateOutlines`, `getOutlineArea`, `getOutlinePerimeter`, `outlineToTurfPolygon`, `metersToUnit`, `checkEdgeSnap`, `checkAlignmentGuides`.
