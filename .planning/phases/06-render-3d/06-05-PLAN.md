**RenderPage.jsx changes:**
1. Import useObjectsHistory: `import useObjectsHistory from "../../hooks/useObjectsHistory";`
2. Instantiate after useOutlineHistory: `const objectsHistory = useObjectsHistory(id);`
3. Destructure: `const { objects, setObjects, canUndo: canUndoObjects, canRedo: canRedoObjects, undo: undoObjects, redo: redoObjects, saveObjects } = objectsHistory;`
4. Add objects state: `const [selectedObjectId, setSelectedObjectId] = useState(null);`
5. Update stageUndo/stageRedo to handle objects stage:
   - When stage === "objects": undo = undoObjects, redo = redoObjects, canUndo = canUndoObjects, canRedo = canRedoObjects
6. Add object CRUD callbacks:
   - `addObject(obj)` → `setObjects(prev => [...prev, obj])`
   - `updateObject(updated)` → `setObjects(prev => prev.map(o => o.id === updated.id ? updated : o))`
   - `deleteObject(id)` → `setObjects(prev => prev.filter(o => o.id !== id))`, clear selectedObjectId
7. Update wrappedSaveAll to also save objects: `if (id && objects.length > 0) await saveObjects(id);`
8. Pass objects and handlers to AssetsPanel, PropertiesPanel, RenderComponent:
   - AssetsPanel: `onSelectCatalogItem={startPlacement}` (from useObjectsPlacement)
   - PropertiesPanel: `objects={objects}`, `selectedObjectId`, `onSelectObject={setSelectedObjectId}`, `onUpdateObject={updateObject}`, `rooms={roomElements}`
   - RenderComponent: `objectsData={objects}`, `selectedObjectId`, `onSelectObject={setSelectedObjectId}`, `onObjectDelete={deleteObject}`
9. Add useEffect for Delete/Backspace key to delete selected object when stage === "objects"
