   - When stage === "render3d": use meshStandardMaterial with higher opacity (0.85), roughness 0.7, metalness 0.1
   - Add floor plane inside each room: a flat mesh at y=0 with the room's fill color
   - Walls should castShadow and receiveShadow
3. For objects stage: keep current behavior (subtle depth, semi-transparent)
