Per D-04 and D-07: Create the placement infrastructure.

**RoomBoundary.js:**
Export two pure functions:

1. `findRoomAtPosition(x, y, rooms)`:
   - Iterate rooms array (each has x, y, width, height, id)
   - Return first room where x >= room.x && x <= room.x + room.width && y >= room.y && y <= room.y + room.height
   - Return null if no room contains the point
   - Include 2px tolerance (matching existing roomContainsPoint pattern)

2. `snapToRoomBoundaries(object, room, snapDistance = 10)`:
   - Accept object { x, y, width, height } and room { x, y, width, height }
   - Clamp object center so it stays within room boundaries:
     - clampedX = max(room.x + objWidth/2 + snap, min(obj.x, room.x + room.width - objWidth/2 - snap))
     - clampedY = max(room.y + objHeight/2 + snap, min(obj.y, room.y + room.height - objHeight/2 - snap))
   - Return { ...object, x: clampedX, y: clampedY, room_id: room.id }
   - If no room, return object unchanged

**useObjectsPlacement.js:**
Per D-04: State machine for placement mode.
- Props: `rooms` (array of room elements for boundary detection)
- State: `{ mode: 'idle' | 'preview' | 'placing', catalogItem: null, ghostPosition: null, targetRoom: null }`
- Methods:
  - `startPlacement(catalogItem)` → sets mode to 'preview', stores catalogItem
  - `updateGhostPosition(x, y)` → calls findRoomAtPosition, updates ghostPosition and targetRoom
  - `confirmPlacement()` → if catalogItem and ghostPosition exist, calls snapToRoomBoundaries, creates new object with per D-09 schema: `{ id: 'obj-{timestamp}{random}', name, type: 'object', category, x, y, width, height, rotation: 0, floor_id: room?.floor_id, room_id: room?.id, fill, modelUrl }`, resets to idle, returns the new object
  - `cancelPlacement()` → resets to idle
- Keyboard: useEffect listening for Escape key to cancel placement
- Return: `{ mode, catalogItem, ghostPosition, targetRoom, startPlacement, updateGhostPosition, confirmPlacement, cancelPlacement, isActive: mode !== 'idle' }`
