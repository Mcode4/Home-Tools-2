**ThreeCanvas.jsx:**
- Import Canvas from `@react-three/fiber`, OrthographicCamera and OrbitControls from `@react-three/drei`
- Props: `stage` ("objects" | "render3d"), `rooms` (array of room elements), `onPointerMissed` (callback)
- Render R3F Canvas with:
  - `gl={{ alpha: true, antialias: true }}` for transparent background
  - `style={{ background: 'transparent' }}` 
  - `orthographic` prop when stage === "objects"
  - Camera setup: position [0, 100, 0], rotation [-PI/2, 0, 0] for top-down view
- For objects stage: OrthographicCamera (makeDefault) + OrbitControls (enableRotate=false, enablePan=true, enableZoom=true, screenSpacePanning=true, mouseButtons LEFT=2 MIDDLE=1)
- For render3d stage: PerspectiveCamera (makeDefault) + OrbitControls (enableDamping=true, dampingFactor=0.1) — placeholder for Wave 6
- Lighting: ambientLight intensity 0.6, directionalLight position [50, 100, 50] intensity 0.8 castShadow
- Render RoomWalls for each room in the rooms prop
- Wrap in Suspense boundary for future GLB loading
- Add onClick handler on Canvas that calls onPointerMissed when clicking empty space (deselect objects)

**RoomWalls.jsx:**
- Import * as THREE from "three", useMemo from react
- Props: `room` (single room object with x, y, width, height, fill), `stage`
- Use useMemo to create ExtrudeGeometry from room rectangle:
  - Create THREE.Shape from room.x, room.y, room.width, room.height
  - Extrude with depth = stage === "render3d" ? 240 : 30 (2.5D has subtle depth)
  - bevelEnabled: false
  - Rotate geometry -PI/2 on X axis so extrusion goes up (Y-axis)
- Render mesh with meshStandardMaterial:
  - color from room.fill || '#6366f1'
  - transparent: true when stage === "objects", opacity 0.3 (so Konva grid shows through)
  - side: THREE.DoubleSide
- Position at [room.x + room.width/2, 0, room.y + room.height/2] to center the extrusion

**Important:** For the 2.5D objects view, rooms should appear as semi-transparent flat extrusions so the Konva floor grid is visible beneath. For 3D render, walls will be taller and more opaque (handled in Wave 6).

Per D-01: Layer the Three.js canvas on top of the existing Konva canvas in RenderComponent.

**RenderComponent.jsx changes:**
1. Import ThreeCanvas at the top: `import ThreeCanvas from "./ThreeCanvas";`
2. Add new props to RenderComponent signature: `objectsData` (array of placed objects), `onSelectObject` (callback), `onPlaceObject` (callback)
3. Inside the component, extract room elements from the elements/floors data:
   - `const roomElements = useMemo(() => (elements || []).filter(el => el.type === "room" && el.floor_id && el.sectionRole !== "base"), [elements]);`
4. Inside the `#render-screen` div (after the existing Konva `<Stage>` element), add the Three.js canvas layer:
   - Wrap in a div with `className="three-canvas-layer"` and conditional style:
     - When stage is "objects" or "render3d": `pointerEvents: 'auto'`
     - Otherwise: `pointerEvents: 'none'`
   - Render `<ThreeCanvas stage={stage} rooms={roomElements} onPointerMissed={() => onSelectShape?.(null)} />`

**RenderComponent.css changes:**
Add the dual-canvas stacking CSS:
```css
.three-canvas-layer {
  position: absolute;
  inset: 0;
  z-index: 2;
  pointer-events: none;
}

#render-screen > .konva-stage,
#render-screen > div:first-child {
  position: relative;
  z-index: 1;
}
```

The key insight: Both canvases occupy the same space. Konva is z-index:1 (bottom), Three.js is z-index:2 (top). Three.js canvas has pointer-events:none by default, switching to auto only when in objects/render3d stage. This prevents event conflicts between the two renderers.

Also ensure the existing Konva Stage has `position: relative` and `z-index: 1` so it stays below the Three.js layer.
