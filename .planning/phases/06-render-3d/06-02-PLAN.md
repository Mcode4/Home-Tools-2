Per D-03: Create `FurnitureCatalog.js` containing the built-in furniture catalog organized by categories.

Structure:
- Export `CATEGORIES` array: `["Bedroom", "Living Room", "Kitchen", "Bathroom", "Office", "Outdoor"]`
- Export `FURNITURE_CATALOG` array of objects, each with:
  - `id`: unique string (e.g., "bed-double", "sofa-3seat")
  - `name`: display name (e.g., "Double Bed", "3-Seat Sofa")
  - `category`: one of the CATEGORIES values
  - `width`: default width in pixels (for 2D placement, ~80-200 range)
  - `height`: default height/depth in pixels (~60-160 range)
  - `height3d`: 3D height for box rendering (e.g., 40 for bed, 80 for sofa)
  - `fill`: default color hex (e.g., "#8B7355" for bed, "#6B7280" for sofa)
  - `icon`: emoji or short label for catalog grid (e.g., "🛏️", "🛋️")
  - `modelUrl`: null for built-in items (will be GLB path if provided)

Include at minimum 3-4 items per category (18-24 total items). Use realistic furniture names and dimensions.

Create `ObjectsTab.jsx`:
- Import FURNITURE_CATALOG and CATEGORIES from FurnitureCatalog.js
- Accept props: `onSelectCatalogItem` (callback when item clicked), `onUploadGLB` (callback for upload)
- State: `activeCategory` (defaults to first category), `searchQuery` (optional filter)
- Render: Category tab buttons at top, grid of catalog items below (each showing icon + name + dimensions), "Upload GLB" button at bottom
- Each catalog item is a clickable div. On click, call `onSelectCatalogItem(item)` with the full catalog item object
- Upload button triggers a hidden file input accepting `.glb,.gltf`. On file select, read as data URL and call `onUploadGLB(file)`
- Style: Follow existing AssetsPanel styling patterns (menu-active class, 220px width, dark theme)
