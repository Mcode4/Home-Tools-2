## v1 Requirements

### Cleanup

- [ ] **CLEAN-01**: Remove all debug console.log statements from production code
- [ ] **CLEAN-02**: Remove unused imports, variables, and dead code across frontend
- [ ] **CLEAN-03**: Implement floors, images, and users Redux reducers with proper logic

### Render Page

- [ ] **RENDER-01**: Render page shows assets menu panel with drawing primitives
- [ ] **RENDER-02**: Render page shows properties menu panel with item properties
- [ ] **RENDER-03**: User can add 2D shapes (rectangles, circles, polygons) to render canvas
- [ ] **RENDER-04**: User can manipulate 2D shapes (move, resize, rotate, delete)
- [ ] **RENDER-05**: User can add 3D elements to render canvas

### Editor

- [ ] **EDITOR-01**: User can see saved custom marker types in the draw menu
